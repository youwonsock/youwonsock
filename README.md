# 유원석 | 게임 클라이언트 프로그래머

게임의 플레이 경험을 구성하는 클라이언트 시스템과 개발 도구를 만드는 프로그래머입니다.

C++와 C#을 기반으로 Unreal Engine, Unity, DirectX 프로젝트를 진행했으며, 게임플레이 시스템·렌더링 및 최적화·에디터 도구 개발 경험을 가지고 있습니다.

## 핵심 역량

- **프로그래밍 언어**: C++, C#, C, TypeScript
- **게임 클라이언트**: 플레이어 이동, Ability/Input 시스템, 비동기 씬 로딩, 오브젝트 풀링, 사운드 시스템
- **렌더링 및 최적화**: Terrain, QuadTree, Frustum Culling, LOD, GPU Instancing, Shader
- **개발 도구**: Unreal Editor Plugin, Unity Editor Tool, Flow Field, Transform Path
- **소프트웨어 설계**: 단계 기반 에이전트 오케스트레이션, 요구사항 추적, 검증 및 복구 흐름 설계

## 구현 분야

### 게임 클라이언트 시스템

플레이어 이동과 입력 처리, Ability 기반 기능 분리, 비동기 씬 전환, 오브젝트 풀링과 사운드 관리 등 게임플레이에 필요한 런타임 시스템을 구현했습니다.

### 렌더링 및 최적화

DirectX 기반 MapTool에서 Terrain 편집과 렌더링 파이프라인을 구성하고, QuadTree 공간 분할·Frustum Culling·LOD·Edge Stitching·GPU Instancing·Shader 기능을 구현했습니다.

### 개발 도구

Unreal Editor Plugin과 Unity Editor Tool을 제작해 반복적인 리소스 처리와 기능 검증을 자동화하고, 각 시스템을 실행 가능한 샘플 씬과 문서로 정리했습니다.
